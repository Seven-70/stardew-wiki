## 本地使用

下载仓库后直接双击 `index.html` 即可，无需服务器与网络。顶栏搜索实时过滤当前页面，按 `/` 或 `Ctrl + K` 聚焦，`Esc` 清空；所有页面支持打印为 A4。

## 目录结构

```
index.html          首页与全部条目
assets/style.css    全站样式（含响应式断点）
assets/app.js       侧栏导航、页内目录、搜索
pages/              15 个章节页面（另含主线任务-完整版）
```
